TROUBLESHOOTING GUIDE:
───────────────────────

"FAP fails to load on Flipper"
  - Check Flipper firmware version (v1.0+)
  - Verify FAP placed in correct directory (/apps/Tools/)
  - Try rebooting Flipper
  - Compare FAP architecture (f7 vs f6 differ)

"App crashes immediately after launch"
  - Check available RAM (~500 KB required)
  - Verify SubGHz module is detected (test with official apps first)
  - Clear Flipper cache: Settings > Storage > Format USB

"No signals detected"
  - Verify RSSI threshold (-95 dBm default is very sensitive)
  - Check for RF sources (WiFi, cellular, walkie-talkies)
  - Try scanning near phone or wireless speaker
  - If still nothing, SubGHz module may be faulty

"JSON export missing"
  - Verify SD card has free space
  - Check file permissions in /ext/ directory
  - Reformat SD card in Flipper if corrupted
  - Try manual export by re-running scan

"Dashboard won't load JSON"
  - Verify file is valid JSON (check with online validator)
  - Ensure file was fully transferred (not corrupted)
  - Try smaller JSON (test with 10 signals first)
  - Clear browser cache and retry
